BMW diagnostics,
no Windows.

Read fault codes, watch live values, run actuator tests and inspect coding data, over a K+DCAN cable or a WiFi adapter. No download, no EDIABAS, no virtual machine, no Windows install.

Platform & connection

Platform Build Connection Requirements
macOS BMacW native, or BMWeb K+DCAN USB · THOR WiFi Native needs no setup. On the web build, USB needs Chrome or Edge.
Windows & Linux BMWeb K+DCAN USB · THOR WiFi USB needs Chrome or Edge. WiFi works in any browser.
iOS & Android BMWeb on the home screen THOR WiFi only Safari on iOS, Chrome on Android. Phones have no USB path.

Which cable

On a computer, either works: macOS, Windows and Linux can all drive a K+DCAN USB cable or a WiFi adapter.

A phone or tablet has no USB path, so iPhone and Android need the WiFi adapter.

Which build

BMacW is the macOS app, and the only build that drives a USB cable without Chrome, since Safari has no Web Serial.

BMWeb is a progressive web app that runs everywhere. For a USB cable it needs Chrome or Edge on the desktop; for a WiFi adapter it needs nothing but a browser. Both read the same decompiled INPA screens and run the same BEST2 virtual machine.
