📁 BMW Files & SP-Daten

BMW diagnostics,
no Windows.

Read fault codes, watch live values, run actuator tests and inspect coding data, over a K+DCAN cable or a WiFi adapter.

Which cable? On a computer, either: Windows, macOS and Linux can all use a K+DCAN USB cable or a WiFi adapter. On a phone or tablet there is no USB option, so iPhone and Android need the WiFi adapter.

Which build? BMacW is the macOS app, and the only one that drives a USB cable without Chrome, since Safari has no Web Serial. BMWeb is a Progressive Web App (PWA) that runs everywhere; for a USB cable it needs Chrome or Edge on the desktop, and for a WiFi adapter it needs nothing but a browser.

Both read the same decompiled INPA screens and run the same BEST2 virtual machine. Neither needs EDIABAS installed.
